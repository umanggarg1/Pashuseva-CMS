# Frontend — CRM

Scaffold for the frontend application using Vite + React + TypeScript + Tailwind.

Quick start (from `frontend/`):

```bash
npm install
npm run dev
```

Notes:

- This is a scaffold with basic layout components (Sidebar, Navbar, PageContainer, Cards).
- Add `shadcn/ui`, Motion, forms, icons, and other UI libraries when implementing the UI.
